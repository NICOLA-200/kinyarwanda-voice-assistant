
# Kinyarwanda Voice Assistant for Humanoid Robots

This project implements a Kinyarwanda voice assistant for humanoid robots, using KinyaWhisper for Automatic Speech Recognition (ASR), basic NLP for question matching, and gTTS for Text-to-Speech (TTS).
